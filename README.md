# 📚 AI 책 출판 에이전시

원고 한 편을 넣으면 7명의 AI 전문가가 **출간 기획서부터 교정본, 표지 콘셉트, 판권면, 보도자료까지** 만들어 주는 Claude Code 에이전트 팀입니다.

## 사용법

이 폴더에서 Claude Code를 실행한 뒤:

```
/publish 내원고.docx
```

일부 단계만:

```
/publish my-novel --단계 교정
```

에이전트를 직접 불러도 됩니다: "copy-editor로 3장만 교정해줘", "marketer한테 보도자료 써달라고 해줘"

## 팀

```
            ┌────────────── 편집장 (/publish) ──────────────┐
원고 → 1 기획편집자 → 2 구성편집자 → 3 교정교열자 ─┬→ 4 사실확인
                                                  └→ 5 북디자이너 ─┬→ 6 제작관리자
                                                                   └→ 7 마케터
```

| 에이전트 | 주요 산출물 |
|---|---|
| acquisitions-editor | 출간기획서 (타깃·경쟁서·제목 후보·권고 등급) |
| developmental-editor | 편집자노트, 제안목차 |
| copy-editor | 최종원고.md, 표기원칙, 교정내역 |
| fact-checker | 검증표, 법적검토(저작권·명예훼손) |
| book-designer | 디자인사양서(판형·조판·표지 3안), 표지시안.html |
| production-manager | ISBN·CIP·납본 절차, 판권면, 인쇄사양서, 정가산정, EPUB |
| marketer | 서점등록문안, 보도자료, SNS 콘텐츠, 프로모션 계획 |

## 결과물 위치

`projects/<슬러그>/` 아래 단계별 폴더(`01_기획` … `07_마케팅`)와 `진행현황.md`.
`진행현황.md`의 **"저자 확인 필요"** 목록부터 보세요.

## 원칙

- 원본 원고는 수정하지 않습니다.
- ISBN·가격·추천사·판매 수치 등은 지어내지 않고 `[확인 필요]`로 남깁니다.
- 법정 절차(ISBN·납본 등)와 법적 검토는 참고용이며, 최신 규정과 전문가 확인이 필요합니다.
