# 디자인 사양서 — 『이로써 아노라』

> 작성: book-designer · 기준 자료: 01_기획/출간기획서.md, 붙여넣은 원고(교정 전)
> 모든 쪽수·두께는 **추정치**다. 최종 수치는 `최종원고.md` 조판 뒤에 다시 잰다.

## 1. 판형

**신국판 152×225mm, 무선 제본, 날개 있는 표지(날개 폭 각 90mm)**

선택 이유
- 독자의 중심이 50~70대 기성 성도다. 큰 글자와 넉넉한 행간이 필요해서 46판(128×188)보다 판면이 넓은 판형이 유리하다.
- 부록 A 질문지(예/아직/잘 모르겠다 기입 칸), 부록 B 구절 표, 부록 E 5주 길잡이 표는 신국판이어야 표가 접히지 않고 펜으로 쓸 공간이 생긴다.
- 국내 기독교 신앙서·소그룹 교재의 표준 판형이라 서가 진열과 교회 일괄 구매에 무리가 없다.

## 2. 예상 쪽수와 책등 두께

### 계산식
| 항목 | 값 |
|---|---|
| 원고 분량(추정) | 공백 포함 약 10만 자 (기획서 10만~12만 자 중 하단, 교정본 확정 후 재계산) |
| 판면 | 110×170mm |
| 본문 | 10.8pt · 행간 18.5pt(약 171%) → 한 줄 약 28자, 한 쪽 약 26줄 |
| 쪽당 실효 글자 수 | 이론상 728자 × 문단·소제목·인용 블록 손실 0.8 ≈ **580자** |
| 본문 순수 쪽수 | 100,000 ÷ 580 ≈ 172쪽 |
| 장 시작 쪽(새 오른쪽 + 여백), 부 표지 4×2쪽 | +약 30쪽 |
| 앞붙이(속표지·일러두기·차례·판권 등) | 약 10쪽 |
| 부록 A~E·참고문헌·지은이 소개(표·기입 칸이 많아 쪽당 글자 수가 적음) | 약 30~36쪽 |
| **합계** | **약 240쪽 (16의 배수로 맞춰 240쪽 권장)** · 원고가 12만 자이면 약 272쪽 |

### 책등 두께
- 본문 용지: **미색 모조 80g** (눈부심이 적어 고령 독자에게 맞다). 한 장(2쪽) 두께가 약 0.1mm.
- 240쪽 = 120장 × 0.1mm ≈ 12mm, 표지 두께 약 0.5mm를 더해 **책등 약 12.5~13mm**로 본다. 표지 시안은 13mm로 그렸다.
- 272쪽이면 약 14mm. **인쇄소에서 용지 견본(가제본)으로 실측한 뒤 확정한다.**
- (참고: 에이전트 지침의 "쪽당 0.1mm"는 "장당(2쪽) 0.1mm"의 오기다. 지침 수정이 필요하다.)

## 3. 본문 조판 사양

### 판면·여백 (신국판 152×225)
| 위치 | 치수 |
|---|---|
| 판면 | 110 × 170mm |
| 위 여백(머리) | 24mm |
| 아래 여백(발) | 31mm (각주와 쪽번호 공간 포함) |
| 안쪽 여백(제본 쪽) | 20mm (무선 제본에서 펼침이 덜하므로 넉넉하게) |
| 바깥 여백 | 22mm |

### 서체 (모두 상업적 이용이 가능한 무료 서체)
| 용도 | 서체 | 크기 / 행간 | 비고 |
|---|---|---|---|
| 본문 | **KoPub바탕 Light** (대안: 본명조 Regular / Noto Serif KR) | 10.8pt / 18.5pt, 자간 -1% | 고령 독자 고려. 10.5pt 밑으로 내리지 않는다 |
| 성경 인용 블록 | KoPub바탕 Light | 10.3pt / 18pt | 아래 '성경 블록' 참고 |
| 장 번호 | Gowun Batang Bold 또는 KoPub바탕 Bold | 14pt, 자간 +20% | "4장"처럼 짧게 |
| 장 제목 | KoPub바탕 Bold | 22pt / 30pt | |
| 장 표제 본문(요일 1:5~2:2) | KoPub돋움 Light | 9.5pt | 장 제목 아래, 회색 60% |
| 소제목(###) | KoPub돋움 Medium | 11.5pt, 위 2행·아래 0.5행 띄움 | 번호 없이 |
| 각주 | KoPub돋움 Light | 8.3pt / 13pt | 아래 '각주' 참고 |
| 쪽번호·하시라 | KoPub돋움 Light | 8pt | |
| 그리스어 | Gentium Plus 또는 Noto Serif (그리스 문자 포함) | 본문과 같은 크기 | 한글 서체에 그리스 문자가 없으므로 대체 서체 지정 필수 |
| 영어 인용(웨슬리 원문) | 본문 서체 라틴 글자 그대로 | 본문과 같음 | 괄호 안 원문은 이탤릭을 쓰지 않는다(괄호로 이미 구분됨) |

### 문단
- 첫 줄 들여쓰기 1자(10.8pt). 소제목 바로 뒤 첫 문단은 들여쓰지 않는다.
- 문단 사이 추가 간격 없음.
- 양끝 맞춤, 한 줄에 한 글자만 남는 끝 줄(과부·고아 줄)은 허용하지 않는다.

### 장 시작 쪽
- 모든 장은 **오른쪽(홀수) 쪽에서 시작**한다. 앞쪽이 비면 백면으로 둔다.
- 위에서 60mm 내려 장 번호 → 장 제목 → 장 표제 본문 순으로 놓고, 그 아래 본문을 시작한다.
- 장 번호 위에 짧은 가는 선(폭 12mm, 0.4pt, 표지 포인트 색 #B8862F)을 하나 둔다. 표지의 '문틀 빛'을 본문에서 이어받는 장치다.

### 부 표지 (제1부~제4부)
- 오른쪽 쪽 단독, 뒷면은 백면.
- 중앙에서 약간 위에 "제2부"(12pt), "다섯 가지 기준"(20pt).
- 원고의 부 도입문(예: "1부에서 우리는 왜 물어야 하는지를 살폈다…")은 **부 표지 다음 왼쪽 쪽**이 아니라, 부 표지 아래쪽 1/3에 9.5pt 돋움으로 짧게 넣는다. 분량이 길면(2부·3부) 부 표지 뒷면에 넣고 백면 규칙을 예외로 한다.

### 하시라(면주)와 쪽번호
- 쪽번호: 아래 바깥쪽, 판면 밑에서 10mm.
- 하시라: 왼쪽 쪽 위 바깥 = 부 이름("제2부 다섯 가지 기준"), 오른쪽 쪽 위 바깥 = 장 제목("5장 계명을 지킴"). 8pt, 회색 55%.
- 장 시작 쪽과 부 표지에는 하시라·쪽번호를 넣지 않는다.

### 반복 요소 스타일

**성경 블록 (원고의 "본문과 배경" 첫머리 인용, 7·8·9·12·13·14장 낭독 본문 자리 포함)**
- 왼쪽 들여쓰기 8mm, 오른쪽 4mm. 행 바꿈은 원고(개역개정 낭독 행 나눔) 그대로.
- 왼쪽에 세로선 0.6pt, 색 #B8862F.
- 끝에 오른쪽 정렬 출처 "(요한일서 1:5~10)" 9pt 돋움.
- 7장 이후의 "[낭독 본문 — 출판 시 개역개정 원문 삽입]" 자리는 같은 블록으로 잡아 두고, 핵심 문장만 있던 원고 형식은 버린다. 대한성서공회 사용 허락 범위가 정해지면 전문을 넣는다. [저자 확인]

**본문 속 짧은 성경 인용**
- 큰따옴표 “ ”로 본문 안에 둔다. 서체·크기 변화 없음. 장절은 각주로(일러두기 원칙).

**기준 한 문장 (각 장 "기준을 한 문장으로")**
- 소제목 아래 한 문장을 12pt KoPub바탕 Medium, 가운데 정렬, 위아래 1.5행 띄움. 장마다 독자가 밑줄을 긋는 문장이므로 눈에 띄게 하되 상자는 쓰지 않는다.

**스스로 살펴보기 (4~8장 끝)**
- 연한 바탕 상자: 배경 #F4EFE6(종이 위 3~4% 톤), 테두리 없음, 안 여백 6mm.
- 제목 "스스로 살펴보기" 10pt 돋움 Medium, 질문은 번호 붙인 목록, 10.3pt.
- 질문마다 아래에 **기입용 빈 줄 2줄**(0.3pt 점선)을 둔다. 개인 묵상용 책이 교재로도 쓰이기 때문이다.
- 상자 뒤 맺음 문단("이 질문들에 '아직'이라고 답했다고 해서…")은 상자 밖 본문으로 둔다.

**연습의 자리 (12·13·14장)**
- '스스로 살펴보기'와 같은 상자 구조. 왼쪽 위에 작은 아이콘 대신 "연습" 글자 라벨(8pt, 자간 +30%, #B8862F).
- 13장 "두 줄 일지"는 상자 안에 예시 칸 2줄(첫 줄 / 둘째 줄)을 그려 준다.

**전통의 증언 · 지금 아픈 사람에게**
- 일반 소제목과 같은 스타일. 따로 상자를 만들지 않는다(장 짜임이 이미 일정해서 상자를 늘리면 쪽이 어지럽다).

**각주**
- 각 쪽 아래, 판면 안. 본문과 각주 사이에 왼쪽 30mm 길이 0.4pt 선.
- 번호는 **장마다 1부터 다시**. 본문 속 각주 번호는 위첨자, 문장 부호 **뒤**에 붙인다(예: 있나이까.¹). 붙여넣은 원고의 `" .` 흔적이 모두 각주 자리다 — 교정 단계의 `[각주]` 표시 목록으로 원본과 맞춘다.
- 각주 서체 8.3pt / 행간 13pt. 성경 장절 각주는 "요일 1:9" 같은 약칭을 쓴다.
- ※ 표시(출판 전 원문 대조 항목)는 **최종 인쇄본에서 반드시 지운다.** 조판 단계에서 ※ 남아 있는 각주를 색으로 표시해 교정쇄에서 걸러 낸다.

**부록 A — 자기 점검 질문지**
- 각 기준이 한 쪽(또는 펼침 두 쪽)에 들어가도록 한다. 기준 5개 × 1쪽 + 안내 1쪽 + 마침 1쪽 = 7쪽 내외.
- 표 구조: | 번호 | 질문 | 예 | 아직 | 잘 모르겠다 |
  - 질문 열 너비 약 70mm, 기입 칸 각 11mm, 칸 안에 □(4mm) 하나.
  - 행 높이 최소 12mm(손으로 표시하기 편하게), 가로 괘선 0.3pt 회색, 세로 괘선 없음.
- 기준 아래 "약속" 문장은 성경 블록과 같은 스타일(세로선).
- "이 질문지를 쓰는 법" 목록의 • 불릿은 그대로 둔다(가운뎃점과 구분할 것).

**부록 B — 구절 표**
- 3열 표: 장:절(15mm) / 무엇으로·무엇을 아는가(가변) / 이 책(18mm).
- 9.5pt, 행 간격 넉넉하게, 짝수 행에 #F4EFE6 바탕. 원고의 `5:18~20"우리가` 줄은 셀이 붙어 있으니 교정본 기준으로 나눈다.
- 그리스어(ἐκ τούτου)는 그리스 문자 대체 서체.

**부록 C — 함께 읽기**
- 장 이름을 왼쪽 열(20mm)에 두는 2열 배치. 질문 ①②는 각각 한 문단.
- 원고의 공백 정렬(“1장      ①”)은 버리고 표 또는 탭 정렬로 다시 짠다.

**부록 D — 어휘 대조표**
- 낱말(굵게, 돋움) → 뜻(본문) → 회색 9pt 괄호 "헷갈리기 쉬운 말 · 다룬 장" 순서의 정의 목록. 표보다 목록이 읽기 쉽다.

**부록 E — 5주 길잡이**
- 한 주 = 반쪽 상자 하나(펼침 두 쪽에 4주 + 다음 쪽에 1주와 맺음말).
- 상자 안 2열 표: 항목(본문/주일 설교/주중 읽기/스스로 살펴보기/함께 나눔) 22mm + 내용.
- 소그룹 1시간 순서(10·10·30·10분)는 가로 막대 하나로 그려 주면 인도자가 한눈에 본다.

**참고문헌**
- 9pt, 내어쓰기(hanging indent) 6mm. 영문 서명은 이탤릭(이 부분만 예외).
- "———." 반복 저자 표기는 원고대로.

### 앞붙이 순서 (권장)
1. 반표제지(책 제목만) 2. 백면 3. 표제지(제목·부제·지은이·[출판사]) 4. 판권면 — **원고에는 판권이 책 끝에 있다. 국내 단행본 관행대로 앞(표제지 뒷면) 또는 끝 중 하나를 고르되, 원고 배치를 존중해 책 끝에 두는 것도 가능하다. [저자 확인]** 5. 일러두기 6. 차례(2쪽) 7. 프롤로그

## 4. 표지 콘셉트 3안

공통 원칙: 책의 중심 낱말은 '고요(헤시키아)'와 '확신'이다. 소리 큰 그래픽, 구름 사이 십자가, 빛줄기 클리셰, 사진 몽타주는 쓰지 않는다. 원고 안의 장면에서 이미지를 가져온다.

### 1안 「밤의 문설주」 ✅ 저자 확정 (2026-11-09)
- **의도:** "그 밤 집의 안전은 집 안 사람들의 마음 상태가 아니라 문밖의 피에 달려 있었다"(12장). 확신의 근거가 '내 안'이 아니라 '문밖'에 있다는 책의 결론을 한 장면에 담는다. 니고데모의 밤(프롤로그)도 겹친다.
- **구도:** 짙은 밤빛 바탕 한가운데, 단순한 선으로 된 문틀 하나. 문틈과 문틀 안쪽에서 따뜻한 등불 빛이 새어 나온다. 인방(위쪽 가로대)에만 아주 가는 짙은 붉은 선 하나 — 피를 직접 그리지 않고 암시만 한다. 사람은 그리지 않는다.
- **제목 배치:** 문틀 위쪽 밤하늘 영역에 세로쓰기 없이 가로로 "이로써 아노라"를 크게(약 48pt 상당), 부제는 문틀 아래 바닥 쪽에 작게.
- **색상 팔레트:**
  - 밤 #1C2433 (바탕) · 밤 그늘 #121826
  - 등불 #E9C77B · 등불 중심 #F6E7C1
  - 문틀 금선 #B8862F
  - 인방의 붉은 선 #7A2E2A
  - 글자 #F3EDE1
- **제목 서체 방향:** 붓맛이 적은 단정한 명조(Gowun Batang Bold / 본명조 Heavy). 자간을 조금 벌려(+4%) 고요하게.
- **장르 내 참고 경향:** 최근 국내 기독교 교양서가 쓰는 '단색 바탕 + 상징 하나 + 단정한 명조' 흐름. 특정 책 디자인을 참조하지 않는다.
- **썸네일 검토:** 온라인 서점 썸네일(약 120px 폭)에서도 '어두운 바탕 속 빛나는 문'이 또렷이 남는다.
- **이미지 생성용 프롬프트 (텍스트 없이):**
  `Minimal book cover illustration, no text, no people. A simple wooden door frame standing alone in a deep navy night, warm lamplight glowing softly from inside through the open doorway and the gaps, a single very thin dark red line along the lintel, quiet and still atmosphere, subtle paper grain texture, flat painterly style with soft gradients, lots of negative space in the upper third for a title, muted palette of navy #1C2433, warm gold #E9C77B, deep red #7A2E2A, vertical 152:225 aspect ratio.`

### 2안 「숯불 곁 새벽」
- **의도:** 9장 디베랴 바닷가. 세 번 부인한 베드로를 다시 부르신 숯불. "기준에 못 미칠 때"의 위로, '하나님은 우리 마음보다 크시고'의 정서.

- **장점/약점:** 가장 고요하고 제작비가 낮으며(그림 의뢰 불필요) 감리교 목회자·소그룹 교재로서 품위가 있다. 다만 서가에서 눈에 덜 띄고, 미색 바탕은 온라인 썸네일에서 흰 배경에 묻힐 수 있다(얇은 테두리 필요).
