# 쪽수 재계산 — 실제 원고 기준 (6단계 제작관리)

> 디자인사양서의 240쪽은 원고를 10만 자로 가정한 추정이었다. 구성 수정 반영본 `최종원고.md`를 실제로 세어 다시 계산한다. 여전히 **추정치**이며, 조판 후 실측으로 확정한다.

## 실제 분량 (2026-11-09, `최종원고.md`)
| 구분 | 글자 수(공백 포함, [각주]·검토 표시 제외) |
|---|---|
| 앞붙이 + 프롤로그 + 본문 1~14장 + 에필로그 | 약 73,200자 |
| 부록 A~E | 약 9,800자 |
| 전체 파일 | 84,810자 (표시 포함) |

## 계산 (디자인사양서 판면 기준: 110×170mm, 10.8pt/18.5pt, 쪽당 실효 약 580자)
| 항목 | 쪽 |
|---|---|
| 본문 순수 쪽수: 73,200 ÷ 580 | 약 126 |
| 각주 공간 (+8%, 각주 217개) | +10 |
| 장 시작 홀수 쪽·장 첫 쪽 여백 (프롤로그·14장·에필로그 = 16개 시작) | +약 20 |
| 부 표제지 4부 × 2쪽 | +8 |
| 앞붙이 (속표지·일러두기·차례 등) | +8 |
| 부록 A~E (표·기입 칸, 쪽당 약 350자) + 부록 시작 쪽 | +약 30 |
| 참고문헌·지은이 소개·판권 | +약 6 |
| **합계** | **약 208쪽** |

- 16쪽 대수로 맞추면 **208쪽(13대)**, 여유를 두면 **224쪽(14대)**.
- **권장: 224쪽(14대)** — 각주 원본(217곳)이 들어오면 각주 길이에 따라 늘 수 있고, 남는 쪽은 백면·메모 쪽(6주 길잡이 기록란)으로 쓸 수 있다.

## 책등 두께
- 가정: 미색 모조 80g, **장당(2쪽) 약 0.1mm = 쪽당 약 0.05mm**, 표지(아트지 250g 내외 + 코팅) 앞뒤 합 약 0.5mm.
- 208쪽: 104장 × 0.1 = 10.4mm + 0.5 ≈ **약 11mm**
- 224쪽: 112장 × 0.1 = 11.2mm + 0.5 ≈ **약 12mm** ← 권장안
- 표지 시안(13mm)은 **12mm로 수정 필요**. 인쇄소 가제본 실측 후 확정.
