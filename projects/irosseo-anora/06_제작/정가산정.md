# 정가 산정 가이드

> 아래 숫자는 **모두 예시값**이다. 실제 인쇄 견적과 유통 조건이 나오면 변수만 바꿔 다시 계산한다.
> 비교 도서 정가는 검색으로 확인하지 못했다 [확인 필요]. 서점에서 같은 분야·비슷한 쪽수(200~230쪽 신국판) 기독교 신앙서 5권의 정가를 직접 확인해 범위를 정한다. 일반적으로 이 분야·분량은 **13,000~17,000원** 범위로 알려져 있다 [확인 필요].

## 변수
| 기호 | 뜻 | 예시값 |
|---|---|---|
| P | 정가 | 15,000원 |
| N | 인쇄 부수 | 1,000부 |
| C_print | 인쇄·제본·용지 총액 | (견적) 예: 3,500,000원 |
| C_fixed | 디자인·조판·교정·ISBN 등 고정비 | 예: 2,500,000원 (자가 출판 시 외주 비용) |
| C_permit | 성경 사용 허락 비용 | [대한성서공회 견적] |
| r | 인세율 (정가 대비) | 10% (자가 출판이면 저자=출판사이므로 0으로 두고 이익에 합산) |
| s | 공급률 (서점·도매에 넘기는 값 ÷ 정가) | 60~70% (온라인 서점·도매 경로) / 교회 직거래는 70~80% 직접 정함 |
| d | 배본·물류비 (부당) | 예: 300원 |

## 공식
- 1부당 순수입 = `P × s − P × r − d`
- 손익분기 부수 = `(C_print + C_fixed + C_permit) ÷ (P × s − P × r − d)`

## 예시 계산 (출판사 경유, 정가 15,000원, s=65%, r=10%, d=300원)
- 1부당 순수입 = 15,000×0.65 − 1,500 − 300 = **7,950원**
- 손익분기 = (3,500,000 + 2,500,000 + C_permit) ÷ 7,950 ≈ **약 755부 + (C_permit ÷ 7,950)**

## 예시 계산 (자가 출판, 교회 직거래 위주: 정가 15,000원, 교회 공급가 = 정가의 75%, r=0, d=200원)
- 1부당 순수입 = 11,250 − 200 = **11,050원**
- 손익분기 ≈ 6,000,000 ÷ 11,050 ≈ **약 543부 + 사용 허락 비용분**

## 정가 제안
- **14,000원 안팎** (176쪽, 신국판, 무선) — 쪽수가 224쪽 가정보다 48쪽 줄어 제작비가 낮아짐. 비교서 확인 후 13,000~15,000원 사이에서 확정. (2026-11-09 각주 포함 조판 결과 반영)
- 6주 공동 읽기용 **단체 구매가**는 별도 표(10권·30권·50권 이상 구간)로 정한다 → 07_마케팅/프로모션계획.md의 단체 구매 제안서와 맞출 것.
- 도서정가제: 신간은 정가의 최대 15% 이내(가격 할인 10% + 경제상 이익 포함) 할인만 허용 — 단체 구매 할인도 이 범위를 지켜야 한다 [최신 규정 확인 필요].
