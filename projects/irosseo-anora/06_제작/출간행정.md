# 출간 행정 체크리스트 — 『이로써 아노라』

> 절차·기간·비용은 바뀔 수 있다. 이 세션에서는 국립중앙도서관·대한성서공회 사이트에 직접 접속하지 못했으므로, 모든 항목은 **[최신 규정 확인 필요]**.

## 0. 먼저 정할 것
- [ ] **출간 방식** [저자 확인]: ① 기존 출판사 투고 ② 자가 출판(1인 출판사 등록) ③ 출판 대행. ①이면 아래 1~4는 출판사가 처리한다.
- [x] **펴낸 곳**: 헤시키아 하우스 (저자 확정 2026-11-09). 출판사 신고 시 상호로 등록 — 기존 신고 여부 [저자 확인]

## 1. 출판사 신고 (자가 출판일 때)
- [ ] 관할 시·군·구청에 출판사 신고 → 신고확인증 발급 [최신 규정 확인 필요]
- [ ] 사업자등록(세무서) — 출판업
- [ ] 같은 이름의 출판사가 있는지 미리 조회

## 2. ISBN 발급
- 신청처: 국립중앙도서관 **서지정보유통지원시스템**(seoji.nl.go.kr) — 발행자번호 신청 → 도서별 ISBN 신청 [최신 규정 확인 필요]
- **부가기호 제안: `03230`** [확인 필요]

| 자리 | 값 | 뜻 | 근거 |
|---|---|---|---|
| 1 (독자대상) | 0 | 교양 | 일반 성인 성도 대상 |
| 2 (발행형태) | 3 | 단행본(무선 제본) | 신국판 무선 |
| 3~5 (내용분류) | 230 | KDC 기독교 | 국내 기독교 일반서 다수가 쓰는 값으로 알려짐 |

  - 대안: 신앙생활 세분류(23X) 값이 더 맞는지 KDC 6판 분류표로 확인할 것. 검색으로 확정하지 못했다.
  - 전자책을 내면 **전자책 ISBN을 따로** 받는다 (발행형태 자리 값이 달라짐).

## 3. CIP(출판예정도서목록)
- [ ] 서지정보유통지원시스템에서 ISBN과 함께 신청 → 판권면에 CIP 제어번호 기재 [최신 규정 확인 필요]

## 4. 납본

- [ ] 납본 보상금 청구 가능 여부 확인
