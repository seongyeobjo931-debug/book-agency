# 표기 원칙 — 『이로써 아노라』

기준: 한글 맞춤법, 표준어 규정, 외래어 표기법, 문장 부호 규정(2015 개정), 표준국어대사전. 저자의 「일러두기」에 적힌 원칙을 우선한다.

## 1. 성경 인용
- 개역개정 직접 인용은 **원문 그대로** 둔다. 옛 어미(-나이까, -지니라, -노라)와 개역개정의 띄어쓰기(예: "가인 같이", "그 때부터", "도와 줄")도 고치지 않는다.
- 직접 인용은 큰따옴표 " ". 따옴표 없이 풀어 쓴 간접 인용은 본문 맞춤법을 따른다(예: 빌 3:7 풀어 쓴 문장 "해로 여길뿐더러").
- 장절 표기
  - 본문 문장 안: '요한일서 5장 13절', '3장 20절'
  - 괄호 안: '(1:9)', 요한일서는 책 이름 생략 가능
  - 장 머리 본문 표제와 부록 표: '요한일서 1:5~2:2'처럼 쌍점·물결표 형식을 쓴다(일러두기의 예외, 저자 확인 항목).
  - 범위는 물결표 '~'(예: 3:14~18).
  - 부록 A의 약칭은 '요일'.

## 2. 문장 부호
- 책·단행본: 『 』 — 『성경전서 개역개정판』, 『이로써 아노라』, 『기독교 강요』
- 설교·문서·장 제목·설교 시리즈: 「 」 — 「거의 그리스도인」, 「성령의 증거」, 「두 증거」, 「이로써 아노라」(설교 시리즈)
- 강조·용어: 작은따옴표 ' ' — '막연한 신앙', '종의 믿음'
- 쌍점: 앞말에 붙이고 뒤는 띄운다 — "핵심 문장: …", "약속: …"
- 가운뎃점: 나열·묶음에 '·'(U+00B7)를 쓰고 앞뒤를 붙인다 — 시간·장소·인물, 5·6장. 원고의 '•'는 모두 '·'로 바꾸었다. 목록 기호(일러두기, 부록 A 사용법)는 마크다운 목록으로 바꾸었다.
- 줄표: '—'(앞뒤 띄움)는 저자 원고대로 둔다.
- 줄임: 인용 안 생략은 '…'(한 개)로 저자 원고대로 통일되어 있다.
- 연이은 인용문 사이는 한 칸 띄운다 — "아마 되었겠지요." "그거야 …"

## 3. 그리스어
- 형식: 작은따옴표 음역 + 괄호 그리스어 — '엔 투토'(ἐν τούτῳ)
- 부록 B의 ἐκ τούτου에도 같은 형식으로 음역('에크 투투')을 붙였다.

## 4. 영어 원문 병기
- 웨슬리 인용의 영문은 원문 철자 그대로 괄호 안에 둔다(예: "calmly sung on"). 번역문 닫는 따옴표 바로 뒤에 붙여 쓴다.

## 5. 고유명사·외래어 (원고 표기 유지)
- 존 웨슬리, 아우구스트 슈팡엔베르크, 올더스게이트, 트리엔트 공의회, 콘스탄티노폴리스, 하이델베르크, 콜카타, 토머스 맥스필드, 조지 벨, 장 칼뱅, 마르틴 루터
- **메소디스트**: 국립국어원 외래어 표기로는 '메서디스트'가 원칙이나, 한국 감리교회 문헌의 관용과 저자 선택을 존중해 원고대로 '메소디스트'로 통일했다(저자 확인 항목).
- 교회 이름: 표제는 '국화교회', 지은이 소개는 '국화감리교회' — 저자 확인 항목.

## 6. 숫자·단위
- 연도·장절·쪽수: 아라비아 숫자(1735년, 5장 13절)
- 셀 수(문장 속): 한글(두 증거, 다섯 기준, 열네 장, 일곱 날, 백 리트라)
- 시간: '10분', '30분'

## 7. 저자 고유 구성 (손대지 않음)
- 장마다 되풀이되는 소제목: 본문과 배경 / 기준을 한 문장으로 / 두 가지 오해 / 전통의 증언 / 지금 아픈 사람에게 / 십자가에서 오는 근거 / 스스로 살펴보기 / 다음 물음
- 평서체 '-다' 문체와 짧은 문장 반복은 의도된 설교 산문의 리듬으로 보고 유지한다.

## 8. 자리 표시
- 붙여넣기 과정에서 사라진 각주 위치: `[각주]` (닫는 따옴표·낱말 바로 뒤, 마침표·쉼표 앞)
- 저자가 채울 자리: `[저자 체험 자리 …]`, `[낭독 본문 …]`, `[대조]`, 판권의 `[____]`는 원고대로 둔다.
